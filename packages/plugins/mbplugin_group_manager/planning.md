# 群聊管理插件

预计功能:

- 自动审核入群
  - 预置审核模板
  - 可配置轮换问题表, 可正则匹配答案, 可配置最大尝试次数 (达到后拉黑, 同意入群后清零)
- 无权限管理时自动在当前群禁用, 普通时候也可以配置禁用
- bot主人(/bot管理员)(/群主/群管理员)(适用范围可配置) 回复群成员消息以 `/warn {reason}`, 用于累计警告次数达到阈值后禁言指定时间, 警告事件可以配置为随着时间逐渐过期, 过期的警告事件不再算入累计警告次数
- 小游戏: 可以玩 "轮盘赌", 按随机顺序上若干枚"实弹"和若干枚"空弹", 群成员"开枪"后若被"击中"则被禁言, 也可能"安然无恙"
- 各群的配置完全隔离, 每个功能都可以被独立禁用
