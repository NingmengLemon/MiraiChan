# Mirai 酱

## 介绍

一个简单的 Bot, 使用 [melobot](https://github.com/Meloland/melobot) 作为框架

> melobot 是一个小巧可爱而强大的机器人开发框架，快去给她点点 star 吧！

名字来自于最初基于的实现端 mirai ~~, 不会起名导致的~~,
